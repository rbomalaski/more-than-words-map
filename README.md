# “These Are More Than Words”: An Interdisciplinary Concept Map for Hip-Hop Scholars

by Rachel Bomalaski, Nov. 2026

"These are more than words, this is more than rap. This is the streets, and I am the trap." Jeezy, *Standing Ovation*

An interactive map of over 8,000 works of hip-hop scholarship in 95 clusters, grouped into twelve overlapping conceptual groupings. It has three views of the same works:

- **Bling view** (`bling.html`): facets and clusters
- **Blob view** (`blob.html`): blobs and clusters
- **Brain view** (`brain.html`): lobes and nodes

Open `index.html`, or any view, in a web browser. Each file is self-contained; the only outside request is for web fonts.

## Data

Every work on the map comes from the dataset *The Scholars Got Something To Say: A South-Facing Dataset for Interdisciplinary Hip-Hop Research*, version 2.0 (8,456 works; the 430 that fit no cluster are not shown). Each work's full citation, the searches that found it, and its tags are in the dataset: https://doi.org/10.5281/zenodo.23933278

## How it was made

Designed by Rachel Bomalaski. Built with AI assistance (Claude, Anthropic), which placed works in clusters by words in their titles and by the dataset's columns. The author decided the conceptual groupings, the clusters, and their names. Placements are a starting point for browsing, not readings of the works.
